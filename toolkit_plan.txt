Tool 1: Simple Calculator
The calculator adds, subtracts, multiplies, and divides two numbers.

Tool 2: To-Do List
The to-do list allows the user to add tasks, view tasks, and remove tasks while the program is running.

Tool 3: Number Checker
The number checker asks the user for a number and determines whether it is positive, negative, or zero.
